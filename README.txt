TANDAR-CNEA — Manual web

Archivos:
- index.html: página principal con el contenido del manual.
- tandar.css: hoja de estilos del sistema TANDAR (sin modificar), para que el manual
  se vea igual que la aplicación. Incluye modo claro/oscuro.
- manual.css: componentes propios del manual (tarjetas, flujo, FAQ, etc.), construidos
  sobre las variables de tandar.css. Se carga después de tandar.css.
- cnea-logo.png: logo de la CNEA (barra de navegación, encabezado, pie y favicon).

Para actualizar el estilo cuando cambie la aplicación: reemplazar tandar.css por la versión nueva.

Para GitHub Pages: subir los archivos al repositorio (descomprimidos), con index.html en la raíz, y activar Settings > Pages > Deploy from a branch.
